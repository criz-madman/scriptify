Text Bounce Expression Workflow & Video Reference Reference Tutorial

Master the After Effects cascading textIndex bounce expression physics

Watch on YouTube →
1. The `textIndex` Stagger Principle

In After Effects, textIndex assigns an incremental index (1, 2, 3...) to each character, word, or line. Multiplying (textIndex - 1) * delay offsets the start time of the physics calculation across each unit.

2. Decaying Sine Wave Formula

Math.sin(t * freq * 2 * Math.PI) / Math.exp(t * decay)

Produces a physical harmonic spring that oscillates back and forth while smoothly decaying to zero rest state.

3. Automatic Rigging in Scriptify

Scriptify automates this entire manual setup: click "Download .jsx Script" to automatically create the text layer, attach the animator with the chosen separation, and wire live sliders on a master controller.

How to Apply & Install in Adobe After Effects Step-by-Step

Complete setup walkthrough for CEP extensions and ScriptUI panels on Windows & macOS

01 Security Setup

Allow Unsigned Panels

Enable Adobe PlayerDebugMode in system settings so After Effects loads custom panels:

  1. Press Win + R, type regedit, and press Enter.
  2. Navigate to registry key:
    HKEY_CURRENT_USER\Software\Adobe\CSXS.11
  3. Right-click in right area → New → String Value.
  4. Name it PlayerDebugMode and set value to 1.
  5. (Repeat for CSXS.12 and CSXS.13 if they exist on your PC).

Open Terminal and execute the following commands:

defaults write com.adobe.CSXS.11 PlayerDebugMode 1
defaults write com.adobe.CSXS.12 PlayerDebugMode 1
defaults write com.adobe.CSXS.13 PlayerDebugMode 1
02 Folder Placement

Unzip into Extensions Folder

Copy your panel files into Adobe's central extensions directory:

CEP Extensions Path:

C:\Users\<you>\AppData\Roaming\Adobe\CEP\extensions\
Path Ending Rule: Ensure files are strictly one folder deep (no nested subfolders):
...extensions\QuickAccess\CSXS\manifest.xml ✓
For ScriptUI (.jsx): Put in Support Files\Scripts\ScriptUI Panels\

CEP Extensions Path:

~/Library/Application Support/Adobe/CEP/extensions/
Path Ending Rule: Ensure one folder deep (e.g. .../extensions/QuickAccess/CSXS/manifest.xml).
For ScriptUI (.jsx): Put in /Applications/Adobe After Effects <Ver>/Scripts/ScriptUI Panels/
03 Launch in AE

Open in After Effects

Launch After Effects to dock and execute your newly built panel:

1 Restart After Effects completely to reload the extensions manifest cache.
2
For CEP Panels: Navigate to top menu:
Window → Extensions → Quick Access
3 For ScriptUI Panels (.jsx): Go to Window and click your script name at the bottom of the list. Dock anywhere!
